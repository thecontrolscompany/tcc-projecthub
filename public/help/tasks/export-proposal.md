# Exporting a Proposal

The proposal export generates a customer-facing `.html` proposal using the standard TCC report style.

## Generating the Proposal

1. Open an estimate.
2. Click **Generate Proposal** in the estimate toolbar.
3. The `.html` file is downloaded automatically.
4. Open the file and use **Print / Save as PDF** when a PDF copy is needed.

## What's Included

The proposal document includes:

- Project name and number
- Customer and site information when entered in project settings
- Pricing summary
- Scope summary by system
- Warranty, clarifications, exclusions, and authorization signature blocks

## What's Excluded

The proposal does not include:

- Assembly-level cost detail
- Component-level pricing
- Labor hour breakdowns

## Template

The proposal uses the standard TCC HTML report style and embeds the logo assets from `public/report-assets/`.
