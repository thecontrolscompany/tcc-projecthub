# Refreshing and Managing Pricing

## How Pricing Works

When a line item is added to an estimate, the current assembly prices are captured in a **price snapshot**. Subsequent price book changes do not affect existing items automatically.

See [Price Snapshots](../reference/price-snapshots.md) for the full explanation.

## Updating an Item to Current Prices

To refresh a line item to the current price book:

1. Open the line item editor.
2. Use the **Update Prices** action to re-capture current assembly prices.

This replaces the stored price snapshot with today's prices.

## Price Book

The **Price Book** tab (internal edition only) shows all assembly definitions with current unit costs. You can:

- Override the price for any assembly
- Import updated prices via CSV
- Export the current price book to CSV

See [Price Book](pricebook.md) for full instructions.
