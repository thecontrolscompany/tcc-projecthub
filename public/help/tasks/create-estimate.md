# Creating and Managing Estimates

## Create a New Estimate

1. Go to the **Estimates** tab.
2. Click **New Estimate**.
3. Enter a project name and number.
4. The estimate opens immediately — set project settings before adding items.

## Open an Existing Estimate

Estimates are listed on the Estimates tab. Click an estimate name to open it.

## Estimate Settings

After opening an estimate, click **Settings** to configure:

- **Wage rate** — fully-loaded labor rate ($/hr)
- **Labor adjustment** — percentage multiplier on all labor (e.g., difficulty factor)
- **Markups** — material markup, labor markup
- **Overhead items** — fixed-cost line items (e.g., PM hours, travel allowance)
- **Equipment rentals** — items billed at cost with no markup
- **Bond rate** — percentage applied to the total
- **Default install type** — EMT or Plenum, applied to new items

## Default Install Type

Set a default install type (EMT or Plenum) in Settings before adding items. Use **Bulk Apply** to update all existing items at once if you need to change it later.

## Deleting an Estimate

From the estimate list, use the delete action on any estimate. This is permanent — there is no undo.
