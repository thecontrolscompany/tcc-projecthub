# Adding Equipment — System Wizard

The System Wizard walks you through system type selection and configuration before opening the line item editor. This ensures the correct components are pre-selected based on your configuration choices.

## Starting the Wizard

1. Click **System Wizard** in the top navigation bar.
2. If you have an active estimate, the wizard will add the item directly to it.
3. If no estimate is active, open one first from the Estimates tab.

## Wizard Steps

**Step 1 — System Type**
Choose the system category: AHU, VAV, FCU, RTU, DX/Heat Pump, VRF, Unit Heater, Central Plant, or Network.

**Step 2 — Configuration**
Select the specific configuration for that system type. Options vary by system:

- AHU: MASD, MADD, OASD, or other air handler variants
- VAV: single duct, fan-powered series/parallel, etc.
- FCU: 2-pipe, 4-pipe, heat pump variants
- DX: straight cool, heat pump
- VRF: indoor unit, outdoor unit, or full system

**Step 3 — Add to Estimate**
Click **Add to Estimate**. The editor opens with components auto-selected based on your configuration. Review and adjust as needed.

## Editing Without the Wizard

To edit an existing line item, click its name in the estimate item list. The editor opens directly — the wizard is only for creating new items.
