# Project Settings

Project settings control how costs are calculated and presented for a specific estimate.

## Opening Settings

1. Open an estimate from the Estimates tab.
2. Click the **Settings** tab inside the estimate.

## Wage Rate

The fully-loaded hourly labor rate applied to all labor hours. This should include wages, benefits, burden, and any other per-hour cost.

## Labor Adjustment

A percentage multiplier applied to all labor. Use this for job difficulty, remote location, or other factors that affect productivity. 100% = no adjustment.

## Markups

- **Material markup** — percentage added on top of material cost
- **Labor markup** — percentage added on top of labor cost

## Overhead Items

Fixed-cost line items added to the estimate total. Common uses: project management hours, travel allowance, commissioning time.

## Equipment Rentals

Items billed at cost with no markup applied. Common uses: lifts, specialized tools.

## Bond Rate

Percentage applied to the total contract value after all other costs and markups.

## Default Install Type

Sets the default EMT or Plenum pricing for new line items. Use **Bulk Apply** to update all existing items.
